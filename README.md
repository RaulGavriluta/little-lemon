# 🍋 Little Lemon Restaurant Web App

> **Capstone Project** for the **Meta Front-End Developer Professional Certificate**

## 📖 Description

**Little Lemon** is a responsive web application developed for a Mediterranean restaurant. The application allows users to browse the food menu, learn about the restaurant's history, and book a table through an interactive reservation form.

This project serves as the final **Capstone Project** required to obtain the **Meta Front-End Developer Professional Certificate**. It demonstrates proficiency in modern web development practices, focusing on UI/UX design, accessibility, and functional React architecture.

## 🚀 Tech Stack

This project was built using the following technologies:

* **[React.js](https://reactjs.org/)**: For building a dynamic and component-based user interface.
* **[Tailwind CSS](https://tailwindcss.com/)**: For rapid, utility-first styling and ensuring a fully responsive design across devices.
* **HTML5 & CSS3**: Semantic markup and layout structure.
* **JavaScript (ES6+)**: Application logic and interactivity.
* **React Router**: For handling client-side navigation.

## ✨ Key Features

* **Responsive Design**: Optimized for Desktop, Tablet, and Mobile screens using Tailwind CSS breakpoints.
* **Table Reservation System**: A fully functional booking form with state management and form validation.
* **Dynamic Routing**: Seamless navigation between Home, About, Menu, and Booking pages.
* **Component Architecture**: Modular and reusable components (Navbar, Footer, Cards, Buttons).
* **Accessible UI**: Built with accessibility standards in mind (ARIA labels, semantic tags).

## 🛠️ Getting Started

Follow these instructions to set up the project locally on your machine.

### Prerequisites
Make sure you have **Node.js** and **npm** installed.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/RaulGavriluta/little-lemon.git
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd little-lemon
    ```

3.  **Install dependencies:**
    ```bash
    npm install
    ```

4.  **Start the development server:**
    ```bash
    npm run dev
    ```

The application will launch in your browser at `http://localhost:3000`.
